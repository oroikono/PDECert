# Fisher--KPP historical source bytes

This data-only snapshot preserves all 18 files named by the existing frozen
Fisher--KPP integrity records. Every file is checked against its original SHA-256,
including the raw response's absence of a final newline. None is imported,
executed, installed, or placed on Python's search path by the current runner.

The bytes were copied from full repository revision
`c962d9c2df4a37bd682fd187e739c8db0edfb1d5`. That revision is a source of matching
archive bytes, **not a claim about the original training commit**. The original
integrity record's `base_revision` is unchanged. `snapshot.json` lists the exact
inventory and repeats the original source hashes for independent inspection.

This is the declared historical source closure, not a complete executable
checkout or an environment lock. Validating it checks source identity; it does
not replay training, numerically regenerate a report, or prove that training
produced the preserved weights. The artifact, historical integrity records,
and historical result remain in their original repository locations unchanged.
